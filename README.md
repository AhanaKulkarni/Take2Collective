# Take2 Collective 🌿
> **Creating spaces for intentional living.**

Take2 Collective brings together ideas, practices, people, and projects exploring what it means to navigate, understand, and build a wholesome adult life. Founded by **Prachiti Mhatre**, Counselling Psychologist (MSc Lifespan Counselling, St. Xavier’s College, Mumbai).

---

## ✨ Features & Architecture

- **Unboxed, Free-Flowing Design**: Custom organic sanctuary aesthetic (warm green, sand, terracotta, sage) with zero rigid card boxes, fluid typography (Fraunces + Lora + Plus Jakarta Sans), and handcrafted botanical SVGs (zero system emojis).
- **Smooth Scroll Experiences**:
  - Live reading progress indicator (`.scroll-progress-line`).
  - Seamless IntersectionObserver scroll reveal animations (`.reveal-on-scroll`, `.reveal-stagger`).
  - Subtle hero leaf parallax.
- **Mobile-First Optimization**:
  - Fully responsive from 320px smartphones to 4K displays.
  - Storybook vertical botanical storyline for the **5 Segments of Adulting**.
  - Touch-smooth horizontal swipe rail with native scroll-snap for community testimonials.
  - Sticky header with glassmorphism blur and animated slide-down navigation drawer.
- **Bilingual English & Marathi Support**: Instant one-click toggle (`🌐 EN | मराठी`) with language persistence.
- **Interactive Regulation Toolkit**:
  - Somatic Sigh with an animated physiological breathing pacer bubble.
  - 5-4-3-2-1 Sensory Orientation check-in.
  - Aspirant study-block de-escalation tool.
  - Warm boundary blueprint.
- **Curated Articles & Multimedia**:
  - In-page modal reader for essays across Therapy, Exam Aspirants, Relationships, and Movement.
  - Video preview modal for Bharatanatyam & Somatics.
  - Workshop photo lightbox.
- **Inclusive Community**:
  - Anonymized testimonials honoring therapeutic privacy.
  - Subsidized competitive exam aspirant fee structure (₹800–₹1000).
  - Verified crisis helpline directory (iCall, Vandrevala Foundation, Aasra, Samaritans Mumbai).

## 🚀 Running Locally

```bash
# Clone the repository
git clone https://github.com/AhanaKulkarni/Take2Collective.git

# Navigate to directory
cd Take2Collective

# Start any local HTTP server
python -m http.server 8000
# or
npx serve .
```

Open `http://localhost:8000/` in your browser.
